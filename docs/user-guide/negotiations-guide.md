# Negotiation and Deal Tracking Guide

Master business opportunity management with iCan's enhanced negotiation tracking system featuring deal pipelines, value tracking, and competitive analysis.

## Deal Overview

The iCan negotiation system helps you track business opportunities with:

- Visual deal pipeline management
- Value and probability tracking
- Competitor analysis
- Expected close date monitoring
- Win/loss analytics
- Activity history per deal

## Deal Structure

Each deal/opportunity includes:

### Basic Information
- **Deal Name** (required): Opportunity title
- **Contact** (required): Primary contact
- **Company**: Associated company
- **Stage**: Current pipeline stage
- **Value**: Deal monetary value
- **Currency**: Value currency (USD, EUR, etc.)

### Probability and Timing
- **Probability (%)**: Likelihood of closing
- **Expected Close Date**: Anticipated completion
- **Created Date**: When deal was created
- **Last Updated**: Most recent change

### Details
- **Description**: Deal overview and details
- **Next Steps**: Planned next actions
- **Competitors**: Competing companies/solutions
- **Source**: How opportunity was identified
- **Tags**: Custom categorization

## Pipeline Stages

Deals progress through these stages:

### 1. Prospecting
- Initial opportunity identification
- Qualification research
- Contact attempts

### 2. Qualification
- Need confirmation
- Budget verification
- Decision-maker identification
- Timeline assessment

### 3. Proposal
- Solution presentation
- Proposal delivery
- Pricing discussion
- Requirement gathering

### 4. Negotiation
- Terms discussion
- Objection handling
- Counter-offers
- Final negotiations

### 5. Closing
- Contract preparation
- Final approval
- Signature collection
- Implementation planning

### 6. Won/Lost
- Deal conclusion
- Post-deal activities
- Analysis and learning

## Creating Deals

### New Deal Creation

1. Navigate to Pipeline view
2. Click "New Deal" button
3. Fill in required fields:
   - Deal name
   - Contact (select from existing)
   - Company (manual text entry)
   - Initial stage
   - Estimated value
4. Add optional details:
   - Probability
   - Expected close date
   - Description
   - Competitors
5. Click "Save"

**Note**: Company names are now entered as simple text fields rather than selecting from existing company records.

### Deal from Contact

Create deals directly from contact profiles:

1. Open contact detail view
2. Click "Create Deal" button
3. Contact automatically populated
4. Fill in deal details
5. Click "Save"

### Deal from Interaction

Create deals from interaction outcomes:

1. Log interaction with business opportunity
2. If interaction indicates deal potential
3. System prompts to create deal
4. Interaction automatically linked to deal
5. Fill in deal details
6. Click "Save"

## Pipeline Management

### Pipeline View

Visual kanban-style pipeline:

- **Columns**: Each pipeline stage (Prospecting, Qualification, Proposal, Negotiation, Closing, Won, Lost)
- **Cards**: Deal cards with key info
- **Drag and Drop**: Move deals between stages with automatic probability updates
- **Stage Dropdown**: Quick stage changes with automatic probability calculation
- **Value Display**: Deal values visible on cards
- **Probability Indicators**: Color-coded by likelihood
- **Terminal States**: "Won" and "Lost" deals cannot be moved back to other columns
- **Terminal Badges**: Visual indicators for completed deals (green for Won, red for Lost)

### Moving Deals

**Drag and Drop**:
1. Click and hold deal card
2. Drag to new stage column
3. Release to move
4. Stage automatically updated

**Manual Move**:
1. Open deal details
2. Change stage dropdown
3. Click "Save"

### Pipeline Customization

Customize pipeline for your business:

1. Go to Settings > Pipeline
2. Modify stage names
3. Add or remove stages
4. Set stage order
5. Configure stage-specific rules

## Deal Value Tracking

### Setting Deal Value

1. Open deal details
2. Enter monetary value
3. Select currency
4. System calculates weighted value:
   - Weighted Value = Deal Value × Probability

### Value Analytics

View value analytics:

- **Total Pipeline Value**: Sum of all deal values
- **Weighted Pipeline Value**: Probability-adjusted total
- **Value by Stage**: Distribution across pipeline
- **Average Deal Size**: Mean value per deal
- **Value Trends**: Changes over time

### Currency Handling

- Multiple currency support
- Currency conversion for reporting
- Base currency selection
- Exchange rate updates

## Probability Management

### Setting Probability

1. Open deal details
2. Use probability slider (0-100%)
3. Or enter specific percentage
4. System may suggest probability based on stage

### Probability Suggestions

System provides probability recommendations:

- **Prospecting**: 10-20%
- **Qualification**: 25-40%
- **Proposal**: 50-70%
- **Negotiation**: 75-90%
- **Closing**: 95%+

### Probability Analytics

Track probability accuracy:

- Historical win rates by probability
- Probability calibration
- Stage conversion rates
- Forecast accuracy

## Competitor Tracking

### Adding Competitors

1. Open deal details
2. Go to "Competitors" section
3. Click "Add Competitor"
4. Enter competitor name
5. Add competitor details:
   - Strengths
   - Weaknesses
   - Their offering
   - Pricing (if known)
6. Click "Save"

### Competitor Analysis

Analyze competitive landscape:

- **Competitor Matrix**: Compare across deals
- **Win Rates vs Competitors**: Performance against specific competitors
- **Common Objections**: Typical competitor-based objections
- **Competitive Intelligence**: Aggregate competitor data
